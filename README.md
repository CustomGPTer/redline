# Redline

Redline is a free interval timer for Android. Pick a workout such as Tabata or the Norwegian 4x4, or build your own, press Start, and it fills the screen with the colour of each block, beeps and speaks every change and keeps going with the screen off. It reads Bluetooth heart-rate straps and keeps a history with streaks and plans. It has no adverts, no accounts and no paid version.
