# Redline

Redline is a free interval timer for Android: 36 ready-made workouts, your own by rounds or block by block, a voice and beeps for every change, heart-rate zones from a Bluetooth strap, and it keeps going with the screen off. No adverts, no account.

Website: https://customgpter.github.io/redline/

Download: https://github.com/CustomGPTer/redline/releases/latest/download/Redline.apk
